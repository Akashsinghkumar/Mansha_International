## 📁 Website Structure

### Pages
- `index.html` — Homepage with Hero Slider, Highlights, Machine Catalog, Stats Counter, Testimonials Slider, Applications Parallax, FAQ, and Consultation Booking.
- `about-us.html` — Company background, mission, why we started, founders' story, knitting partner narrative, and commitment.
- `services.html` — Machine installation, maintenance, technical consultation, and training overview.
- `products.html` — Comprehensive catalog of machinery and spare parts.
- `applications.html` — Industrial textile fabric application showcases (Apparel, Medical, Technical, Automotive textiles).
- `blog.html` — Industry insights, technical maintenance guides, and machine selection tips.
- `contact.html` — Interactive inquiry form, contact details, working hours, and map.
- `faq.html` — Frequently asked questions regarding orders, installation, warranty, and logistics.

### Machinery Categories
- `category-circular-knitting.html` — Overview of Circular Knitting Machinery range.
- `category-single-jersey.html` — High-Speed Single Jersey, 3-Thread Fleece & Terry Circular Knitting Machines.
- `category-double-jersey.html` — SAMES SD-R2 & SD-I4 Interlock & Rib Double Jersey Circular Machinery.
- `category-jacquard.html` — Computerized Electronic Jacquard Circular Knitting Machines (Link, Single, Double & Rib Transfer).
- `category-flat-knitting.html` — Automated Computerized Flat Knitting Machines for Sweaters, Collars, Cuffs & Shaped Panels.
- `category-needles.html` — Precision Latch Needles, Transfer Needles, and Sinker Needles.
- `category-spare-parts.html` — Cams, Feeders, Cylinders, Inverters, and Mechanical Spares.
- `category-second-hand.html` — Certified Refurbished Pre-Owned European & Asian Knitting Machinery.

## 🚀 Running Locally

No build step or Node.js runtime is required. You can serve the static files with any HTTP server:

```bash
# Option 1: Python HTTP Server
python -m http.server 8000

# Option 2: Live Server (VS Code extension or npx)
npx serve .
```

Open your browser and navigate to `http://localhost:8000`.
